Website controls

Manage storefront content and customer-facing settings.

Changes are saved to the server settings in MongoDB. Image uploads require configured Cloudinary; alternatively paste a public HTTPS image URL.

Customer support inbox

Customer messages are emailed through Resend to the configured SUPPORT_EMAIL; this panel only shows legacy browser-local demo messages.

Homepage & footer

Everything customers see on the homepage — banners with model photos, promo tiles, footer text, copyright and social links — is controlled here. Preview storefront ↗

Store name, tagline, top announcement bar, support phone/email and delivery charges are in Website controls. Banners/tiles below are saved together with this form.

Advertisement manager

Create a storefront promotional banner. Save publishes the enabled ad in website settings.

Advertisement settings are stored in MongoDB. An enabled announcement placement is shown in the storefront announcement strip; image/hero placement can be used for a later campaign layout.
